# SimpleLegacyWebApp

## Description
This is a minimal web application using our legacy WebThumbnailViewer and WebAnnotationViewer

NOTE: These controls are still supported in 2026.2 but are considered "legacy" they are not receiving any new features and will only receive bug fixes for critical issues. No new development projects should be started with these controls. However, if you're using them in an existing app, we will make a best attempt to support you.

Please consider moving to our modern WebDocumentViewer (with or without WebDocumentThumbnailer).

You can find a full tutorial in our KnowledgeBase  
[INFO: WebDocumentViewer Whitepaper - Getting Started With Web Viewing](https://www.atalasoft.com/KB2/KB/50370/INFO-WebDocumentViewer-Whitepaper-Getting-Started-With-Web-Viewing)

### WARNING ABOUT LEGACY WEB CONTROLS
The legacy web controls **DO NOT WORK in .NET 5+**. They are strictly limited to .NET Framework.
